Time Series Regression Analysis of Sea Surface Temperatures during El Niño

I developed robust time series regression models to forecast sea surface temperatures (SSTs) during El Niño events using meteorological data from the Tropical Atmosphere Ocean (TAO) buoy array. The dataset, aggregated to daily averages from 1980 to 1998, included variables such as wind velocity, humidity, and air temperature. After addressing non-stationarity and variance instability through transformation and differencing, I evaluated multiple models using AIC, BIC, and F-tests. Residual diagnostics—including ACF/PACF plots and Ljung-Box tests—confirmed the presence of autocorrelated errors, and I found that a regression model accounting for this autocorrelation achieved the best performance (AIC = -2.7, R² = 0.99, RMSE = 0.06), effectively capturing SST variation during El Niño cycles.

Regression Library with F-test for Reduced Regression Coefficients in C++

This C++ library implements linear regression from scratch with a focus on performance and flexibility. Built on xtensor and xtensor-blas for efficient, NumPy-like matrix operations, it supports ordinary least squares with diagnostics such as coefficient estimates, standard errors, and model summaries. It includes F-tests for evaluating reduced models and uses boost::math for statistical inference. The library is modular and extensible, with planned support for confidence intervals, robust regression, and generalized linear models.
